# msl_ingest_credential (Resource)

Manages an MSL5 **Ingest Credential** (`/api/v1/streams/{stream_id}/ingest_credentials`). Passwords are write-only and are never returned by the API. A maximum of 4 credentials per stream is supported.

> **Note**: When importing a credential, the `password` attribute will be unknown. You must add it manually in your configuration.

## Schema

### Required

- `algorithm` (String) Hashing algorithm for the password. One of `SHA256`, `SHA512_256`, `SHA512`, `MD5`. Changing this forces a new resource.
- `password` (String, Sensitive) Password for ingest authentication. Hashed server-side; never returned by the API. Changing this forces a new resource.
- `stream_id` (String) ID of the stream this credential belongs to. Immutable: can only be set during resource creation.
- `username` (String) Username for ingest authentication. Must be a non-empty string. Changing this forces a new resource.

### Optional

- `description` (String) Optional description for this credential.
- `expiry_date` (String) RFC3339 expiry date for the credential. When omitted or null, the credential does not expire.

### Read-Only

- `id` (String) The unique credential ID assigned by the MSL5 API.



## Import

terraform import msl_ingest_credential.enc1 <stream_id>/<credential_id>
